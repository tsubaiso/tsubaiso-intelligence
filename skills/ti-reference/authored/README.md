# authored/ — 組織固有レシピ・注釈置き場

利用組織固有の定番SOQL・注意書き・項目の意味補足をMarkdownで自由に追記するフォルダです（ファイル名は自由）。再生成の影響を受けません。

製品標準のレシピ・意味付けは Tsubaiso Atlas MCP サーバー（ツバイソ保守）が実行時に配信し、ここには組織固有の知識だけを置きます。

全利用組織に共通して役立つ内容（標準機能の読み方・標準データの定番集計）をここに書き溜めても、他組織へは配られません。そうした内容に気づいたらツバイソへ連絡してください。意味定義側へ収録すれば、クライアント無操作で全接続先へ反映されます。
