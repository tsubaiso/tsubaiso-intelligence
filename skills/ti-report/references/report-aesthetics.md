# 美しい帳票の原則・サーバPDFとの両立・日本向け/海外向けの様式差

帳票の「美しさ」は趣味ではなく、**読み手が一目で要点（誰宛・いくら・いつ）を掴め、誤読や改ざんが起きにくい状態**を指す。美しさを生む原則は全顧客共通の標準ノウハウ・ブランドの具体値は顧客固有（下の二層モデル）。

## 美の原則

1. **整列とグリッド**: 全要素を共通の基準線に揃える。数値列は右寄せ＋等幅数字で桁を縦に揃え、明細・合計・税内訳の右端を一本の縦線で通す。列幅は固定し、行ごとに踊らせない。左右のブロックは縦罫線で分離する。
2. **タイポグラフィ階層**: 書体は1つ（和文・欧文それぞれ1書体）に統一し、大きさと太さだけで階層を作る。強調は色でなく太さで行う。タイトルは字間を広げると格式が出る。
3. **余白とリズム**: 用紙余白を広めに取り、要素間の縦アキを揃えてリズムを作る。明細に空行を数行確保して箱の均整を保ち、「これで全部」という区切りも与える。詰め込みは美観と可読性を壊す。
4. **罫線の節度**: 罫線の色と太さを統一する。外枠・見出し罫は濃く、補助線は淡く。二重線を避け、罫線は「意味の境界にだけ」引く。
5. **要点の強調**: 最も目立つ要素は1つに絞る＝総額（ご請求金額／TOTAL）。大きな数字＋下罫線または地色帯で1か所だけ強く見せる。アクセント色は1色だけ、限定箇所に使う。
6. **色の節度**: 文字色は純黒を避け、副次情報はグレー。地色は淡いトーン1〜2色。印刷で地色・罫線が飛ばないよう指定する。多色は安っぽさと印刷事故の元。
7. **A4規律**: 用紙はA4固定、内容幅をA4−余白に収める。画面プレビューはA4枠化して、広いモニタでの横長間延びを防ぐ（枠化は画面のみ・PDF出力は変えない）。

## サーバ側PDFと美観の両立

美しさは**サーバ側PDFの制約内**で達成する。サーバ側PDFは旧レンダラのCSS制約が強い（実機実証済・プラットフォーム更新で緩和されうるドリフト対象・出典と実証状態を注記して扱う）。

- **多段組・左右ブロックは、間隔プロパティでなく表のセル＋縦罫線で作る**。間隔は余白や空セルで作る。
- **和文を含む帳票は、サーバPDFで確実に描画される書体を書体指定の先頭に置く**（未指定で全角が脱落しうる）。大きさ・太さ・罫線・薄い地色での階層付けは旧レンダラでも安全。
- 数値の桁揃えは右寄せセルで担保する（旧レンダラでも右寄せは効く）。

## 日本向けと海外向けの様式差

同じ「請求書」でも商慣行が異なる。テンプレ選択と整形で吸収する（差込点の規約は共通、出す値と様式が違う）。

| 観点 | 日本向け | 海外向け |
|---|---|---|
| 言語・書体 | 和文。和文書体。サーバPDF時は対応書体を先頭に | 英文。欧文書体 |
| 文書名 | 「御請求書」「御見積書」を字間広めで | 大文字・中央・下罫線 |
| 宛先・敬称 | 「御中／様」・宛名に下線 | ラベル方式・敬称なし・宛名は太字 |
| 挨拶文 | 定型挨拶あり | なし（事務的） |
| 金額・通貨 | 円・整数・3桁区切り・記号を後置・税込総額を最大に | 小数2桁・記号を前置・インコタームズ併記 |
| 消費税 | インボイス登録番号の表示・税率別内訳・税抜/消費税/税込の三段 | 税欄なし（輸出免税等）・代わりに原産国・支払条件 |
| 承認の標 | 角印（社印） | 署名欄。角印は通常なし |
| 決済情報 | 振込先（銀行・支店・口座種別・番号・名義） | 銀行名・支店・口座番号・国際送金コード |
| 物流情報 | 通常なし | 出荷・船積み欄 |
| 日付書式 | 「西暦年月日」（必要に応じ和暦） | 英文月名 |
| 品目列 | 品名・数量・単価中心 | 型番・製造番号列が一般的 |

日本向け/海外向けは別テンプレートとして持ち、共通の差込規約で流し込む。税・通貨・日付・敬称の差は整形に寄せ、テンプレは差込点と様式だけを担う。片方にしか無い項目（登録番号・国際送金コード等）は源の有無を会社固有層で実証してから対応づける。

## 二層モデル（道具と型は標準・あてはめは顧客ごと）

| 層 | 含むもの |
|---|---|
| **標準（道具と型）** | テンプレの差込DSL・流し込みエンジン・標準項目の意味定義マッピング・美の原則・設計書/仕様書の出力フォーマットとサイクル手順 |
| **顧客固有（あてはめ）** | 顧客固有レイアウトの取込→テンプレ生成・独自項目のdescribe実証→マッピング・配置先の決定・ブランド具体値（ロゴ・色値・書体選択・差出人）・各帳票の項目/指示の中身・様式選択 |

デザインの**原則**は標準、ブランドの**具体値**は顧客固有。取り違えない。

## 美観セルフチェック（帳票テンプレのWrite直前）

1. 数値列は全て右寄せ＋桁が縦に揃っているか（合計・税内訳・明細の右端が一本の線で通るか）。
2. タイトル＞発行者/総額＞見出し＞本文＞注記 の大きさ階層が崩れていないか。強調を色でなく太さで行っているか。
3. 罫線の色・太さが統一され、補助線は淡く・外枠は濃く、意味の境界にだけ引かれているか。
4. 最も目立つ要素が総額1か所に絞られ、アクセント色が1色・限定箇所か。
5. 明細に空行が確保され箱が均整か。余白が詰まりすぎていないか。
6. サーバPDF対象なら、間隔プロパティを使わず表組みか、対応書体が先頭か、画面のA4枠化が入っているか。
7. 日本向け/海外向けの様式（敬称・挨拶・税表示・押印 vs 署名・通貨・物流欄）が対象国に合っているか。
