# ベータとして先行提供している機能の扱い（beta-status）

Tsubaiso Intelligence には、**正式に提供している機能**と、**正式提供に先立って先行して提供している機能（ベータ）**がある。利用者が、いま使っているものがどちらなのかを判断できる状態にしておく。

## ベータとは何か

**実装は完了していて、実際に使える。** 正式提供の前に先行して提供しているという位置づけであり、「動かないかもしれないもの」という意味ではない。

| | ベータでも保証されること | ベータでは保証されないこと |
|---|---|---|
| 動作 | 記述どおりに動く。動かないものはベータとしても出さない | — |
| 安全弁 | 書込前の承認ゲート・検証先行・本人権限の範囲は正式提供と同じく効く | — |
| 仕様 | — | **記述が変わることがある。** 手順・判定・出力の形が更新される |
| 呼び名 | — | **機能名・節の名前が変わることがある。** 利用者の手順書に固定で書き写すと追随が要る |
| 窓口 | — | **個別の問い合わせ対応の範囲が正式提供と異なることがある。** 契約条件に従う |

## 表示のしかた（3層）

**3層すべてに置く。1つでも欠けると、どこかの経路で利用者に届かない。**

| 層 | 置く場所 | 書き方 |
|---|---|---|
| **1. 本文** | 該当スキルの `SKILL.md` の見出し直後、または該当する節の冒頭 | 引用ブロックで1行。**ここが正本** |
| **2. 一覧** | 該当スキルの frontmatter `description` の先頭 | `【ベータ】` の6文字だけ |
| **3. 公開の窓口** | 配布物の `README` | どれがベータで、正式提供が何かを表にする |

### 1. 本文（正本）

書き方は次の形にする。

> **ベータとして先行提供している機能です。** 記述が変わることがあります。扱いは ti-core の `references/beta-status.md` を参照してください。

**スキル全体ではなく一部の機能だけがベータのときは、スキルの冒頭ではなく該当する節の冒頭に置く。** 全体に掛けると、正式提供の機能まで先行提供に見える。

### 2. `description` の先頭

`description` の値の先頭に `【ベータ】` を置く。

**`【ベータ】` 以外の語を足さない [REQUIRED]。** `description` はどのスキルを発火させるかの判定に使われるため、説明文を書き足すと発火の精度が変わる。理由・条件・保証範囲は本文と本 reference に置く。

### 3. `README`

ベータの機能を表で並べる。**利用者が最初に見るのはここなので、抜けると「未完成のものを黙って配っている」と受け取られる。**

## 守ること

- **frontmatter に独自のキーを足さない [REQUIRED]。** `status: beta` のようなキーは共通仕様（Agent Skills）に無く、検証で弾かれることがある。ベータかどうかは本文・`description`・`README` の3層だけで表す。
- **ベータであることを理由に、できないことをできると書かない。** ベータは提供の段階を表すもので、記述の厳密さを緩める根拠ではない。裏づけの規律は正式提供と同じ。
- **「いつ正式提供になるか」を書かない。** 時期を書くと、その時期が来たときに配布物が先に古くなる。段階が変わったときに表示を外す。
- **利用者の環境に届いているかを、版で判定しない。** どの版から使えるかは組織によって食い違うことがある。**現に使えるかは `capability-preflight.md` の自己診断で確かめる。**

## 正式提供に切り替えるとき

**3層を同時に外す [REQUIRED]。** 1つでも残ると、正式提供の機能がベータのままに見える。

1. 該当スキルの本文から引用ブロックを削除する
2. `description` の先頭から `【ベータ】` を削除する
3. `README` の表から行を削除する
4. スキルの `version` を上げる（表示の変更は利用者への意味が変わるため patch ではなく minor）

## ベータの機能の一覧

**現在ベータとして先行提供している機能は、`README` の一覧を正本とする。** 本 reference は扱いの型だけを持ち、どれがベータかは持たない（二重ホームにしない）。

## 分担

| 層 | 役割 |
|---|---|
| ti-core（本 reference） | ベータの定義・表示の型・切り替えの手順 |
| `README` | いまどれがベータかの一覧（正本） |
| 各スキル | 自分の本文と `description` に表示を置く |
| `capability-preflight.md` | その組織で現に使えるかの自己診断 |
