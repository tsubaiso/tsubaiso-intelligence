# Tsubaiso Intelligence Skill

Tsubaiso Intelligence（サービス）の**配布スキルパッケージ（プラグイン）**です。PSA/IMA（Salesforce）業務を Claude が支援するためのスキル群を収録します。

> 用語: 「Tsubaiso Intelligence」はサービス総称、「Tsubaiso Intelligence Skill」は本配布物（プラグイン）の名称です（GLOSSARY 準拠）。

## 本数の数え方（対外表記の根拠）

製品ページ・提案書で「スキル◯本」と書くときの定義。

| 対外表記 | 定義 | 数え方 |
|---|---|---|
| スキル | `skills/` 直下の `SKILL.md` の数 | `ls skills/*/SKILL.md \| wc -l` |
| 詳細文書を含めた本数 | 上記＋各スキルの `references/*.md` | 上記＋`ls skills/*/references/*.md \| wc -l` |

実測（main・2026-09-25）: スキル**15本**＋詳細層**48本**＝**63本**。うち `ti-core` は横断の土台なので、作業の種類として数えるなら14。**数は増えるので、対外文書には下限表現（「60本超」）で書く。**

## 使い方

1. 標準（ホステッド）Salesforce MCP を接続する（[Salesforce標準MCPサーバー接続ガイド](https://support.tsubaiso.jp/hc/ja/articles/58638669783065)）
2. Tsubaiso Atlas MCP を接続する（意味・ルール・定番レシピの配信元）
3. Tsubaiso Knowledge MCP を接続する（製品の仕様・操作手順の引き当て先）
4. `skills/ti-reference` のスキルを読み込む
5. PSA/IMA のデータについて尋ねる（オブジェクト探索・SOQL 作成・結果のリンク化）

2 と 3 は、**管理者が組織のコネクタとして登録したうえで**、各利用者が一覧から選んで連携し、本人でサインインします（登録の手順は `skills/ti-rollout` §3）。**どの範囲まで取得できるかはサーバー側が本人の資格で判定する**ため、接続する側で範囲を設定する項目はありません。3 を接続しないと、製品の仕様・操作手順を尋ねられたときに AI が引き当て先を持たない状態になります（扱いは `skills/ti-core/references/knowledge-lookup.md`）。

## 提供の段階（正式提供とベータ）

収録スキルの機能には、**正式に提供しているもの**と、**正式提供に先立って先行提供しているもの（ベータ）**がある。ベータの機能も実装は完了していて実際に使えるが、**記述や呼び名が変わることがある**。扱いの詳細は `skills/ti-core/references/beta-status.md` を参照。

| スキル | ベータとして先行提供している機能 |
|---|---|
| `skills/ti-report` | **スキル全体。** 帳票のレイアウト・項目のカスタマイズ（テンプレの作成・調整、差込、押印/DRAFT分岐、org への配置） |
| `skills/ti-spec-view` | **スキル全体。** 顧客がorgへ加えたカスタマイズ仕様の可視化（一覧・標準との差分・業務的意味・確信度と鮮度） |
| `skills/ti-onboarding` | **スキル全体。** 導入プロジェクトの工程進行（計画立案・タスク分解・Fit&Gap の整理・稼働後の新規業務の設計検討） |
| `skills/ti-navigate` | **スキル全体。** 利用組織の実際のメニュー構成に基づく画面の場所・開き方・レコード間の移動経路の案内 |
| `skills/ti-howto` | **スキル全体。** 製品の使い方・可否・仕様の問いに、ナレッジを引いて出典つきで答える入口 |
| `skills/ti-update` | **承認前チェック**（`references/approval-support.md`）と**承認操作の代行**（`references/approval-execution.md`）。入力支援は正式提供 |
| `skills/ti-metadata` | **アップグレード再検証のみ**（`§アップグレード再検証`）。バージョンアップが既存カスタマイズへ与える影響の事前点検。差分方式のメタデータ設定は正式提供 |
| `skills/ti-local-automation` | **顧客レシピの作成・配布のみ**（`§顧客レシピの作成・配布`）。ローカルスクリプトによる API 操作そのものは正式提供 |
| `skills/ti-data-load` | **自動作成シーム経由の生成のみ**（`references/migration-principles.md §自動作成シーム経由で下流を生成する`）。運用テスト・研修データの生成に用いる。一括投入・移行そのものは正式提供 |
| `skills/ti-core` | **サポート起票のみ**（`references/support-escalation.md`）。未解決をまとめてサポートへ引き継ぐ導線。他の共通機構は正式提供 |

**この表が、いまどれがベータかの正本。** 各スキル側の表示（本文の1行と `description` 先頭の `【ベータ】`）は、この表と一致する。**スキルの一部の機能だけがベータのときは `description` に `【ベータ】` を付けない**（付けるとスキル全体が先行提供に見えるため）。この場合、本文の1行は該当する reference の冒頭にある。

## 位置づけ（置き場分離）

- 本リポジトリ＝**配布スキル**（低 IP の雛形・スクリプト）。
- 意味・ルール・定番レシピの本体は Tsubaiso Atlas MCP サーバーが実行時に配信し、本パッケージには同梱しない。
- 製品の仕様・操作手順は Tsubaiso Knowledge MCP サーバーが実行時に配信し、本パッケージには同梱しない。
- 書込前構造ゲートも Atlas MCP の更新系ツールを実行時に参照する。**意味定義・構造スナップショットの同梱はゼロ**で、本パッケージにローカルの意味定義ファイルは残っていない。

## フェーズ

読み取りの意味・ルール・レシピも、書込前構造ゲートが使う構造情報も、Tsubaiso Atlas MCP サーバーが実行時に配信する（同梱ゼロ）。

本パッケージは低 IP のみで構成されるため、**public マーケットプレイスとして配布**する。マーケットプレイスを一度登録すれば以後の改訂・スキル追加を受け取れ、登録にあたって招待・認証・追加課金は要らない。**利用可否を決めるのは配布物へのアクセスではなく、Tsubaiso Atlas MCP サーバーからの意味定義配信**で、契約の終了にともなって配信を停止する。
